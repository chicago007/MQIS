# MQIS (Market Quant Investment System) 버전관리

## Git

저장소 루트는 프로젝트 디렉터리입니다. `.venv/`, `__pycache__/`, `.env`, 시크릿은 커밋하지 않습니다. 규칙은 `.gitignore`를 따릅니다.

아직 커밋이 없다면:

```bash
cd MQIS
git init
git add README.md CHANGELOG.md docs app.py mqis requirements.txt .gitignore .streamlit/config.toml
git status
git commit -m "$(cat <<'EOF'
Initial commit: MQIS 0.1.0 dashboard and docs.

EOF
)"
```

원격은 https://github.com/chicago007/MQIS (퍼블릭)입니다.

```bash
git remote add origin https://github.com/chicago007/MQIS.git
git push -u origin main
```

## 브랜치

| 브랜치 | 용도 |
| --- | --- |
| `main` | 동작하는 최신. 직접 큰 수정을 넣지 않는다 |
| `feat/<topic>` | 기능 |
| `fix/<topic>` | 버그 |
| `docs/<topic>` | 문서만 |

한 브랜치는 한 주제. `main` 반영은 머지(또는 PR) 후.

```bash
git checkout main
git pull
git checkout -b feat/iron-source
# 작업 후
git checkout main
git merge feat/iron-source
```

강제 푸시(`push --force`)는 `main`에 쓰지 않습니다.

## 커밋

- 한 커밋은 한 이유. 메시지 첫 줄은 명령형, 50~72자.
- 본문에는 왜 바꿨는지를 적습니다.
- `.env`, 키, `secrets.toml`은 올리지 않습니다.

예시:

```
Add FRED fallback for Europe LNG.

PNGASEUUSDM is monthly; TTF futures cover the daily gap when FRED times out.
```

## 버전 번호

[Semantic Versioning](https://semver.org/lang/ko/) `MAJOR.MINOR.PATCH`

| 자리 | 언제 올리는지 |
| --- | --- |
| MAJOR | 호환이 깨지는 변경 (유니버스 키 삭제, 스냅샷 스키마 파괴) |
| MINOR | 기능 추가 (지표, 매크로, 화면 섹션) |
| PATCH | 수집 폴백, 표시 버그, 문서 |

현재: **0.1.0** (`mqis/__init__.py`의 `__version__`).

릴리스 절차:

1. `CHANGELOG.md`에 항목을 적는다.
2. `__version__`을 맞춘다.
3. 커밋 후 태그:

```bash
git tag -a v0.1.0 -m "MQIS 0.1.0"
git push origin v0.1.0
```

## 변경 이력

사용자에게 보이는 변경은 모두 [CHANGELOG.md](../CHANGELOG.md)에 남깁니다. 날짜는 태그 기준입니다.
