# MQIS (Market Quant Investment System) 아키텍처

MQIS (Market Quant Investment System)는 수집 → 스냅샷 → 표시의 단방향 파이프라인입니다. UI(`app.py`)와 CLI는 시장 스냅샷(`build_snapshot`)과 섹터 스냅샷(`build_sector_snapshot`)을 화면별로 따로 부릅니다.

```
Yahoo / 네이버 / FRED / Stooq / CNBC
              │
              ▼
        mqis.fetch
              │
        ┌─────┴──────────────┐
        ▼                    ▼
build_snapshot        build_sector_snapshot
시장·지수 퀀트         섹터 ETF 분류·이격도
```

## 모듈

| 모듈 | 책임 |
| --- | --- |
| `mqis/config.py` | 티커, 그룹, 기간, 임계값. 매직넘버는 여기만 |
| `mqis/fetch.py` | OHLCV·수급. 소스 폴백과 `DataFrame.attrs` (source, freq, unit) |
| `mqis/indicators.py` | MA, ADX/DMI, Force, ATR, BB Width, RSI, Stoch, OBV, RS |
| `mqis/signals.py` | 카드용 숫자·라벨·톤, 퀀트 블록과 종합점수 |
| `mqis/sectors.py` | ETF 테마 분류, 동일명 거래대금 중복 제거, 섹터 수익률·거래대금·이격도 |
| `mqis/data/etf_universe.txt` | 섹터 퀀트 유니버스. 이 파일에 없는 종목은 쓰지 않음 |
| `mqis/pipeline.py` | `build_snapshot()`, `build_sector_snapshot()` |
| `mqis/__init__.py` | `__version__` (SemVer). UI·CLI가 여기를 읽음 |
| `app.py` | Streamlit. `@st.cache_data` TTL 300초. 사이드바에 **데이터 새로고침**, 상단·사이드바·하단에 버전 |
| `mqis/__main__.py` | CLI |
| `gemini_web/sector_quant.py` | Gemini Web 전용 독립 섹터 퀀트. MQIS import 없음 |

한국 지수는 Yahoo `^KS200` 공백이 있어 네이버 `siseJson` (KOSPI / KOSDAQ / KPI200)을 씁니다. 지수 거래량이 0이면 SPY/QQQ/SOXX 등 ETF 거래량으로 덮습니다.

## 스냅샷 필드

`build_snapshot()` 반환 dict:

- `generated_at`, `asof` (us / kr 최신 일자)
- `market`: 미국 지수, 거시, 한국 수급
- `quant`: 종목별 이격도·지표·블록 라벨·종합
- `flows`, `prices`: UI 차트·원본

거시 행은 `source`, `freq`(`D`/`M`)를 가질 수 있습니다. 월간이면 화면은 1D 대신 MoM을 보여줍니다.

`build_sector_snapshot()` 반환 dict:

- `generated_at`, `asof`, `count` (중복 제거 후 종목 수)
- `sectors`: 섹터별 단순평균과 구성 ETF 행
- 각 행: 1/5/10일 수익률·거래대금, 이격도 20/60/120

화면 표는 퍼센트·억원을 숫자로 두어 정렬이 크기순이 되게 합니다.

## 설계 제약

- 수집 실패는 예외로 전체를 죽이지 않고 해당 키를 비웁니다.
- pykrx 1.2.8 로그인 수집은 쓰지 않습니다.
- 시그널은 참고용 라벨이며 주문 로직과 분리합니다.
