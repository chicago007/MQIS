# MQIS (Market Quant Investment System) 아키텍처

MQIS (Market Quant Investment System)는 수집 → 스냅샷 → 표시의 단방향 파이프라인입니다. UI(`app.py`)와 CLI(`python -m mqis`)는 같은 `build_snapshot()`을 씁니다.

```
Yahoo / 네이버 / FRED / Stooq / CNBC
              │
              ▼
        mqis.fetch
              │
              ▼
       mqis.pipeline.build_snapshot
         ├─ signals.market_snapshot   시세·수급 카드
         └─ signals.quant_signals     지표·라벨·종합점수
              │
        ┌─────┴─────┐
        ▼           ▼
     app.py     python -m mqis
```

## 모듈

| 모듈 | 책임 |
| --- | --- |
| `mqis/config.py` | 티커, 그룹, 기간, 임계값. 매직넘버는 여기만 |
| `mqis/fetch.py` | OHLCV·수급. 소스 폴백과 `DataFrame.attrs` (source, freq, unit) |
| `mqis/indicators.py` | MA, ADX/DMI, Force, ATR, BB Width, RSI, Stoch, OBV, RS |
| `mqis/signals.py` | 카드용 숫자·라벨·톤, 퀀트 블록과 종합점수 |
| `mqis/pipeline.py` | `build_snapshot()` — 서울 시각 `generated_at` |
| `app.py` | Streamlit. `@st.cache_data` TTL 300초 |
| `mqis/__main__.py` | CLI |

한국 지수는 Yahoo `^KS200` 공백이 있어 네이버 `siseJson` (KOSPI / KOSDAQ / KPI200)을 씁니다. 지수 거래량이 0이면 SPY/QQQ/SOXX 등 ETF 거래량으로 덮습니다.

## 스냅샷 필드

`build_snapshot()` 반환 dict:

- `generated_at`, `asof` (us / kr 최신 일자)
- `market`: 미국 지수, 거시, 한국 수급
- `quant`: 종목별 이격도·지표·블록 라벨·종합
- `flows`, `prices`: UI 차트·원본

거시 행은 `source`, `freq`(`D`/`M`)를 가질 수 있습니다. 월간이면 화면은 1D 대신 MoM을 보여줍니다.

## 설계 제약

- 수집 실패는 예외로 전체를 죽이지 않고 해당 키를 비웁니다.
- pykrx 1.2.8 로그인 수집은 쓰지 않습니다.
- 시그널은 참고용 라벨이며 주문 로직과 분리합니다.
