# MQIS (Market Quant Investment System) 데이터소스

가격·수급은 벤더 재배포이며 지연이 있습니다. 카드 하단의 source가 실제 사용된 경로입니다.

## 미국·일반 거시

Yahoo Finance. 티커는 `mqis/config.py`의 `MACRO`, `US_INDICES`.

| 키 | 이름 | 심볼 |
| --- | --- | --- |
| SPX / NDX / SOX | S&P500 / Nasdaq100 / SOX | `^GSPC` / `^NDX` / `^SOX` |
| TNX / US2Y | 10년 / 2년 | `^TNX` / `2YY=F` (실패 시 FRED `DGS2`) |
| VIX / DXY | VIX / 달러지수 | `^VIX` / `DX-Y.NYB` |
| WTI / NG | WTI / 헨리허브 | `CL=F` / `NG=F` |
| GOLD / HG | 금 / 구리 | `GC=F` / `HG=F` |
| BTC | Bitcoin | `BTC-USD` |

## BDI · 철광석 · LNG

설정에서 `yahoo: False`이고 아래 순서로 받습니다.

| 키 | 1순위 | 2순위 | 3순위 |
| --- | --- | --- | --- |
| BDI | FRED에 Baltic Dry 시리즈 없음 | Stooq `bdiy` / `bdi` | CNBC/Investing `.BADI` |
| IRON | FRED `PIORECRUSDM` (IMF 월간, USD/t) | Stooq `tr.f` | Investing/SGX `TIO=F` |
| LNG | FRED `PNGASEUUSDM` (EU 가스 월간, USD/MMBtu) | — | Investing/ICE `TTF=F` (EUR/MWh) |

FRED CSV가 멈추면 8초 후 다음 소스로 넘어갑니다. `FRED_API_KEY`가 있으면 `api.stlouisfed.org`를 먼저 호출합니다. Stooq가 HTML(봇 체크)을 주면 CSV로 보지 않습니다.

FRED 월간은 보통 1~2개월 지연입니다. TTF는 EUR, IMF LNG는 USD라 소스가 바뀌면 레벨을 비교하면 안 됩니다.

## 섹터 ETF

사용자가 지정한 `mqis/data/etf_universe.txt` 목록만 씁니다. 네이버 전체 ETF를 긁지 않습니다.

분류는 `mqis/sectors.py`의 `SECTORS` / `SECTOR_THEMES`입니다. 순서: 반도체, AI인프라, 2차전지, 방산우주, 조선, 바이오헬스, 자동차, 로봇, 건설, 원자력, 에너지화학, 금융, IT서비스, 소비재, 기타. 로봇이 자동차보다 앞이라 `피지컬AI`/`휴머노이드`는 로봇입니다. 소비재 키워드(경기·필수·생활소비재 포함)는 기타가 아닙니다.

운용사 접두어를 뺀 종목명이 같으면 당일 거래대금이 큰 ETF만 남깁니다. 일봉은 네이버 `fchart`이며 거래대금은 종가×거래량입니다.
